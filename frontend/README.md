# AfriGrow — Mobile App

The Expo (React Native) app for AfriGrow. See the [main README](../README.md) for the full setup, including the backend.

## Quick start

```bash
npm install
cp .env.example .env.local   # add EXPO_PUBLIC_WEATHER_API_KEY
npm start
```

Before running, change the backend IP (`192.168.0.159`) to your computer's local IP in `app/(tabs)/chatbot.tsx`, `components/PlayButton.tsx` and `components/TextWithPlay.tsx`.
